# ZFT Tools 0.1.0-dev.8

Adds `registerGroup(moduleId, { title, icon, order, tools })` and `unregisterGroup(moduleId)` to the existing toolbar API. Existing shared ZFT Tools registration remains supported. Group owner modules control their own callbacks and permissions.

Install in Foundry V13 test world before/with Overland Travel v0.4.0-dev.2. Both must be enabled. The Overland group has an amber-gold compass icon. V14 not yet live verified.
